# Author photo drop zone

Place the author portrait at:

- `assets/author.jpg` (recommended: 800×800 PNG/JPG/WebP, square, will be cropped to circle)

If `author.jpg` is absent, the lander gracefully falls back to `author-fallback.svg`.

A second copy lives in `gHashTag/t27/docs/assets/author-dmitrii-vasilev.jpg` for the t27 repo.
