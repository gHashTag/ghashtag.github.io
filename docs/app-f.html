F.1 Scope

This appendix manifests the three bitstreams produced by the openXC7 flow (yosys + nextpnr-xilinx + prjxray, Docker, no Vivado) for the QMTech XC7A100T-1FGG676C (Xilinx Artix-7, 101k LUT, 240 DSP — 0 used). Each artefact is reproducible from the source trees referenced in Ch.28 and bench-measured per Ch.34.

F.4 Reproduction recipe

git clone https://github.com/gHashTag/trios-fpga
cd trios-fpga && git checkout v3.0-PhD
docker run --rm -v "$PWD:/work" \
  ghcr.io/openxc7/openxc7:2026-q1@sha256:<pin> \
  make -C /work hslm_full_top.bit SEED=1597
sha256sum build/hslm_full_top.bit  # expect: <TBD post-mint>

Sealed seed F₁₇=1597 (sanctioned per Ch.13 #395 STROBE).
